# 合成报告样例

[doctor-report.pdf](doctor-report.pdf) 是 1.3.1 的实际浏览器打印输出，使用 `tests/e2e/fixtures.js` 中的 `reportChartCase()`，与 README 中的两张报告预览来自同一份 PDF。

日期范围为 2023-12-30 至 2024-02-02，5 条记录均为软件验收构造，不包含实际患者日记或姓名。12 月、1 月、2 月新增记录分别为 3、1、1 次；跨年延续和主动确认无头痛均来自明确的测试输入。生成时间由测试运行时的本机时间产生。

这是一份 6 页 A4 PDF。文字和 SVG 图表保留为矢量内容，字体子集已内嵌；正文 11 pt、表格 10 pt，日期与辅助说明至少 9 pt。PDF 放大查看和打印时可读取原始文字，而 README 中的 PNG 是 300 dpi 的预览。

样例用于说明软件输出和统计口径，不是患者病例、临床评估或医疗机构出具的报告。
